FEATURE 01 · LIBRARY

라이브러리는 생성 이미지를 다시 찾고 편집하는 공간입니다

기능 설명

Gemini에서 만든 이미지를 한곳에서 찾아 다시 열고, 추가 편집·다운로드·공유로 이어가는 공간입니다.

1
Gemini 메뉴에서 Library를 열어 생성 이미지를 찾습니다.
2
이미지를 확대해 다운로드하거나 공유 옵션을 확인합니다.
3
Edit 구체적 요청으로 바꿀 부분과 유지할 부분을 지정합니다.
추천 Library는 재편집용으로 쓰고, 확정본은 원본 크기로 내려받아 Drive의 프로젝트 폴더에도 보관하세요.
FEATURE 02 · NOTEBOOK

노트북은 채팅 · 파일 · 지침을 묶어 프로젝트 지식을 이어갑니다

기능 설명

과거 채팅 · 문서 · PDF · 맞춤 지침을 모아 Gemini가 공통 맥락으로 사용하며 NotebookLM과 소스가 동기화됩니다.

1
New notebook을 선택하고 프로젝트 이름을 붙입니다.
2
관련 채팅을 이동하고 파일 · 소스 · 지침을 추가합니다.
3
오디오 · 영상 · 인포그래픽으로 지식을 확장합니다.
추천 과목 · 고객 · 프로젝트별로 노트북을 분리하고, 소스는 파일명을 명확히 붙이세요.
FEATURE 03 · SPARK

Spark는 24시간 업무를 이어가는 개인 AI 에이전트입니다

기능 설명

Google Cloud 가상머신에서 실행되어 기기가 꺼져도 백그라운드 작업을 계속하며 Connected Apps와 연동됩니다.

1
Spark에서 목표 · 완료 시점 · 소스를 설명합니다.
2
제안된 계획 · 연결 앱 · 권한 확인 지점을 검토합니다.
3
Tasks/Schedules에서 진행 상황을 관리합니다.
추천 뉴스 다이제스트 · 메일함 정리처럼 되돌리기 쉬운 일부터 시작하세요.
FEATURE 04 · IMPORT CODE

코드 가져오기는 GitHub 저장소를 분석 자료로 붙입니다

기능 설명

GitHub 저장소나 브랜치를 첨부해 코드 구조 · 함수 · 오류 · 개선안을 저장소 맥락으로 질문할 수 있습니다.

1
Add files > More uploads > Import code 선택
2
GitHub 저장소 또는 브랜치 URL 입력
3
구조 설명 → 위험 찾기 → 수정 제안 질문 진행
제약 웹 전용, 채팅당 저장소 1개 (최대 5,000파일 · 100MB). 자동 동기화 안 됨.
FEATURE 05 · CANVAS

Canvas는 문서 · 앱 · 슬라이드 · 코드를 대화 옆에서 만들고 다듬습니다

기능 설명

Gemini 대화와 편집 화면을 나란히 두고 특정 영역만 선택해 실시간으로 수정하고 내보냅니다.

1
+ > 도구 더보기 > Canvas 선택 또는 생성 요청
2
목적 · 대상 · 형식을 말해 첫 결과물 생성
3
영역 선택 후 톤 · 기능 수정 및 내보내기
FEATURE 06 · PERSONAL INTELLIGENCE

개인 인텔리전스는 내 Google 정보로 맞춤 도움을 만듭니다

기능 설명

과거 대화의 기억, Gmail · Photos · YouTube 정보, 지정 응답 지침을 조합해 맞춤 답변을 제공합니다.

1
Settings > Personal Intelligence에서 기능 사용 선택
2

3
Sources 확인 및 정정 적용

01 · OVERVIEW

Antigravity는 여러 AI 에이전트를 지휘하는 개발 작업 공간입니다

기능 설명

Google의 에이전틱 개발 플랫폼으로, 목표를 설명하면 에이전트가 파일 · 터미널 · 브라우저를 사용해 수행합니다.

사용법

1. 개발 목표 한 문장 정리
2. Antigravity 앱에서 프로젝트 생성 및 작업 폴더 연결
3. 작은 작업 요청 후 단계별 검증

02 · PRODUCT MAP

앱 · IDE · CLI · SDK는 같은 에이전트를 서로 다른 방식으로 사용합니다

CLI

SDK

프로그램 커스텀 통합
