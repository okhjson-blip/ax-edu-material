CONCEPT

Claude Code는 답변보다 “프로젝트의 실제 변경”을 만듭니다

일반 Chat

질문에 답하고 문장을 만듭니다. 로컬 프로젝트 파일을 직접 바꾸는 작업은 기본 목적이 아닙니다.

Code 탭

선택한 폴더를 읽고 → 계획하고 → 파일을 수정하고 → 명령과 테스트로 검증합니다.

DIFF · FILE

Diff는 전체 변경 검토, File은 작은 직접 수정에 씁니다

Diff 패널
  • 파일 목록에서 변경 하나씩 선택
  • + 추가 / − 삭제 라인 확인
  • 특정 줄에 댓글 작성
  • Review code로 결함 점검
File 패널
  • 대화나 Diff의 파일 경로 클릭
  • 작은 수정 후 Save
  • 외부 변경 충돌 시 Override/Discard 선택
Tip 변경을 승인하기 전에 “왜 바뀌었는지” 설명할 수 있어야 합니다.
BROWSER · TERMINAL

결과 화면과 실행 로그를 앱 안에서 함께 확인합니다

Browser 패널

  • HTML · PDF · 이미지 · 영상 열기
  • Claude가 클릭 · 입력하며 자체 검증
  • 외부 사이트는 별도 승인
Terminal 패널
  • 현재 세션 폴더에서 명령 실행
  • Claude와 같은 환경 공유
  • 여러 터미널 탭 사용
  • Local 세션에서만 제공

단축키: Cmd/Ctrl+Shift+B (Browser) · Ctrl+` (Terminal)

CLI VS DESKTOP

같은 Claude Code 엔진을 쓰지만, 검토 방식과 자동화 수준이 다릅니다

공통점 같은 기본 엔진과 프로젝트 파일, settings.json · CLAUDE.md · MCP 설정을 공유합니다.
Desktop 앱

• 시각적 검토와 병렬 작업에 강함
• Diff · File · Terminal · Browser 패널 지원
• Local · Cloud · SSH 환경을 여러 세션으로 관리
• 비동기 작업, PR 검토, 화면 미리보기에 적합

CLI

• 스크립트와 터미널 자동화에 강함
• 터미널에서 대화형으로 실행하고 도구·파일로 연결
• claude -p · pipe · JSON 출력으로 반복 작업 자동화
• 플래그로 모델 · 권한 · 도구 · 출력 형식을 정밀 제어
• CI/CD · 원격 서벗 · 셸 스크립트에 연결할 때 적합

Tip 처음 배우거나 변경을 눈으로 검토할 때는 Desktop으로 시작하고, 반복 실행과 파이프라인이 필요해지면 CLI로 확장하세요.
