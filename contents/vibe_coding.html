PART 1 · 03 페이지 03
DEFINITION

Vibe Coding: 자연어로 의도를 말하고 결과로 방향을 잡는 방식

2025년 등장한 표현으로, 코드 문법보다 '원하는 느낌과 결과'에 집중하는 개발 방식

🌟 초보자에게 주는 기회
  • • 복잡한 문법을 외우기 전 아이디어를 작동하는 프로토타입으로 제작
  • • 비개발자도 데이터 분석 및 업무 자동화 도구를 즉시 구현
  • • 빠른 시도와 즉각적인 피드백 확인 가능
⚠️ 놓쳐서는 안 될 핵심 책임

이해 · 검토 · 테스트의 최종 책임까지 AI에 넘길 수는
없습니다.

속도는 AI가 획기적으로 높이지만, 방향 설정과 결과에 대한 판단, 비즈니스 책임은 사람이 담당합니다.

COMPARE

“그냥 실행”에서 “설명 · 검토 · 검증”으로 성숙하기

업무용 · 고객용 결과물을 만들기 위해서는 성숙한 엔지니어링 방식으로 전환해야 합니다.

🌱 순수 Vibe Coding (초기 실험용)
  • • 원하는 느낌/결과만 말함
  • • 생성된 코드를 거의 읽지 않음
  • • 오류 발생 시 무작정 재요청
  • • 빠른 개인 아이디어 프로토타입에 유리
🛡️ AI 보조 엔지니어링 (업무/상용 수준)
  • • 명확한 요구사항과 완료 조건을 명시
  • • 코드 변경점(Diff)과 외부 의존성을 직접 확인
  • • 단위 테스트 및 보안 검사 수행
  • • 배포 후 실제 운영 및 예외 처리까지 고려

대화형 개발의 5단계 반복 루프

좋은 결과물은 단 한 번의 '마법 프롬프트'가 아니라 짧고 명확한 반복에서 탄생합니다.

1
의도 정의

사용자와 해결할 문제 및 제약 명시

2

AI가 요구조건에 맞춘 코드 작성

3
직접 실행

브라우저, 엑셀, 터미널 등에서 실행

4
관찰/대조

5

실습 미니 실습 1

소프트웨어 없이 AI에게 처음 요청해보기

설치 없이 채팅창에서 좋은 요청의 4대 구조(목표·맥락·제약·완료조건) 연습

  1. 1 아무 AI 챗봇(ChatGPT, Claude 등)을 엽니다.
  2. 2 “엑셀에서 두 열의 숫자를 더하는 함수를 알려줘. 초보자도 이해할 수 있게 예시와 함께 설명해 줘”라고 요청합니다.
  3. 3 답변에서 ‘수식 예시’와 ‘설명’이 명확히 분리되어 있는지 확인합니다.
  4. 4 “더 짧게, 함수 하나만”처럼 추가 제약조건을 입력하여 답변이 실시간으로 바뀌는지 관찰합니다.
TIP: 이 미니 실습의 목적은 완성도가 아니라 ‘요청 → 결과 → 조건 추가 → 재요청’의 기본 흐름에 익숙해지는 것입니다.

SECURITY

API 키 · 비밀번호 · 고객 데이터는 프롬프트에 넣지 않습니다

⚠️ 이미 노출했다면 텍스트 삭제에 그치지 말고 키를 즉시 폐기 및 재발급해야 합니다.

✅ 이렇게 합니다 (권장)
  • • 환경변수(.env)와 시스템 비밀 저장소 사용
  • • 가명 또는 합성 샘플 데이터로 사전 테스트
  • • 필요한 최소 폴더만 도구에 공유
  • • 읽기/쓰기 권한을 분리하고 외부 전송 여부 확인
❌ 이렇게 하지 않습니다 (금지)
  • • API 키, 토큰, DB 접속 비밀번호를 프롬프트에 붙여넣기
  • • 주민번호, 건강, 금융정보 등 민감 개인정보 입력
  • • 고객 원본 데이터나 회사 비공개 소스코드 전체 투입
  • • 운영 서버 자격증명을 대화창에 노출

PERMISSIONS

에이전트 권한은 필요한 폴더 · 명령 · 시간에만 최소 부여

Full Access(전체 권한)는 편리함이 아니라 사용자의 책임 범위를 무한정 넓히는 설정입니다.

1 파일

작업 중인 프로젝트 폴더만 읽기 · 쓰기 허용

2 명령

파일 삭제, 패키지 설치, 배포 명령 전 사람 승인

3 네트워크

검증되고 꼭 필요한 외부 도메인만 통신 허용

4 외부 행동

이메일 발송, 결제, SNS 게시 전 반드시 사람 확인

SUPPLY CHAIN

실제 서비스 배포 전 체크리스트

실습VBA 미니 실습

코드 없이 매크로 버튼만 눌러보기

VBA 모듈을 생성하고 3줄짜리 매크로를 실행하는 기본 구조 익히기

  1. 1 엑셀을 열고 [개발 도구] 탭 확인 (없으면 [파일] > [옵션] > [리본 사용자 지정]에서 활성화)
  2. 2 [개발 도구] > [Visual Basic]을 열어 코드 에디터 화면을 확인합니다.
  3. 3 [삽입] > [모듈]을 클릭해 빈 모듈을 생성합니다.
  4. 4 아래 3줄을 입력하고 F5 키로 실행합니다:
Sub 인사말()
    MsgBox "안녕하세요"
End Sub

AI가 안정적인 코드를 작성하도록 입력과 완료 기준을 구체화합니다.

Excel VBA 매크로를 작성해 줘.
[입력]
- 시트명: 원본 / 1행 제목, 2행부터 데이터
- B열: 담당자, E열: 매출

import shutil
from pathlib import Path
from datetime import date

INPUT_DIR = Path("RPA_Practice/Input")
OUTPUT_DIR = Path("RPA_Practice/Output")

def get_today_folder() -> Path:
    today_str = date.today().isoformat()  # 예: '2026-08-12'
    target_folder = OUTPUT_DIR / today_str
    target_folder.mkdir(parents=True, exist_ok=True)
    return target_folder

def find_pdf_files(folder: Path):
    if not folder.exists():
        return []
    return sorted(folder.glob("*.pdf"))
💡 mkdir(parents=True, exist_ok=True)는 폴더가 이미 있어도 에러 없이 안전하게 실행됩니다.

중복을 건너뛰며 복사하고 결과 출력하기

shutil.copy2로 메타데이터를 보존하고 재실행 시 중복 복사를 방지합니다.

def organize_invoices():
    target = get_today_folder()
    files = find_pdf_files(INPUT_DIR)
    
    if not files:
        print("[안내] Input 폴더에 처리할 PDF 파일이 없습니다.")
        return
        
    copied, skipped = 0, 0
    for f in files:
        dest = target / f.name
        if dest.exists():
            skipped += 1
            continue
        shutil.copy2(f, dest)
        copied += 1
        
    print(f"✅ 처리 완료: 복사 {copied}건 / 건너뜀 {skipped}건 → {target}")

if __name__ == "__main__":
    organize_invoices()

function render(rows) {
  const total = rows.reduce((s, r) => s + r.value, 0);
  const avg = rows.length ? Math.round(total / rows.length) : 0;
  
  document.querySelector('#kpis').innerHTML = `

  const max = Math.max(1, ...rows.map(r => r.value));

      <div class="bar" style="height:${(r.value/max)*150}px;"></div>

    </div>
  `).join('');
}

PROMPT

좋은 프롬프트는 4가지를 담습니다

목적, 입력값, 출력 형식, 제약 조건을 구체적으로 전달할수록 결과가 정확해집니다.

1. 목적: 무엇을 만들지 한 문장으로 명확히 전달
2. 입력값: 사용자가 입력할 항목과 위젯 형태(숫자 입력창 2개, 연산자 드롭다운 등)
3. 출력 형식: '계산하기' 클릭 시 결과를 어떤 레이아웃으로 표시할지 명시
4. 제약 조건: 0으로 나누는 경우 등 예외 처리 규칙 명시 
Streamlit으로 계산기 웹앱을 만들어 줘.
- 입력: 숫자 두 개를 입력받는 입력창 2개, 사칙연산(+, -, *, /) 선택 selectbox
- 동작: '계산하기' 버튼을 누르면 연산 결과를 큰 글씨로 화면에 표시
- 제약: 0으로 나누는 경우 친절한 오류 안내 문구 표시

실습 1

기본 사칙연산 계산기 구현

st.number_input과 st.selectbox를 활용한 기본 웹앱

💻 코드 예시 (calculator_app.py)
import streamlit as st

st.title("🧮 초간단 계산기 웹앱")
num1 = st.number_input("첫 번째 숫자", value=0.0)
num2 = st.number_input("두 번째 숫자", value=0.0)
op = st.selectbox("연산자", ["+", "-", "×", "÷"])

if st.button("계산하기"):
    if op == "+": res = num1 + num2
    elif op == "-": res = num1 - num2
    elif op == "×": res = num1 * num2
    elif op == "÷":
        res = "0으로 나눌 수 없습니다." if num2 == 0 else num1 / num2
    st.success(f"결과: {res}")
🎯 확인 포인트
  • • 브라우저에 숫자 입력창 2개와 연산자 선택 메뉴 표시
  • • '계산하기' 클릭 시 즉시 결과가 박스에 표시
  • • 0으로 나누기 시도 시 에러 대신 친절한 안내 문구 출력
