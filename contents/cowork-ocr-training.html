학습 목표

자동 정리의 마지막 단계는 사람의 확인입니다.

이 과정을 마치면 이미지에서 추출할 항목과 작성 규칙을 지정하고, 결과의 누락·중복·불확실한 값을 확인할 수 있습니다.

화면을 중심으로 재구성한 교육 자료입니다. 아래 요청문은 실습을 돕기 위해 정리한 예시입니다.

01
준비

실습 폴더만 연결하기

영수증 이미지만 모은 별도 폴더를 준비합니다. 다운로드 폴더 전체를 연결하기보다 이번 실습에 필요한 파일만 담은 폴더를 선택합니다.

따라 하기

실습용 이미지 복사 → Cowork에서 작업 폴더 선택 → 선택된 폴더 확인

기억할 점 폴더 선택은 작업 범위를 정하는 단계입니다. 이 과정에서는 파일 삭제 금지와 민감정보 제외도 요청문에 명시합니다.
02
작업 지시

시작 전에 작업 규칙 전달하기

선택한 폴더에서만 작업하도록 요청하고, 불확실한 값은 추측하지 않고 “확인필요”로 표시하게 합니다. 파일 생성·수정 후에는 변경 내용을 요약하도록 요청합니다.

따라 하기

작업 폴더 제한 · 원본 삭제 금지 · 민감정보 제외 · 불확실한 값 표시

기억할 점 이미지 안의 문구는 추출 대상 데이터입니다. 작업 지시는 사용자가 입력한 요청문으로 구분합니다.
03
대상 확인

이미지 목록부터 확인하기

곧바로 결과만 요청하기보다 어떤 이미지가 처리 대상인지 먼저 확인합니다. 파일명과 영수증으로 보이는지 여부를 살펴 누락되거나 섞인 파일을 점검합니다.

따라 하기

대상 파일 목록 확인 → 처리 대상 점검 → 추출 시작

기억할 점 원본 파일명을 결과에 남기면 나중에 잘못 읽은 값을 원본과 쉽게 대조할 수 있습니다.
04
정보 추출

OCR과 표 정리를 나누어 이해하기

OCR은 이미지 속 글자를 읽어 텍스트로 바꾸는 과정입니다. 읽은 날짜·업체명·항목·금액을 정해진 열에 배치하면 경비 정리용 표가 됩니다.

따라 하기

이미지 읽기 → 항목 추출 → 표 생성 → 합계 계산

기억할 점 표가 보기 좋게 만들어졌더라도 원문을 정확히 읽었다는 뜻은 아닙니다. 추출과 검수를 별도 단계로 생각하세요.
05
출력 설계

열과 작성 규칙을 구체적으로 지정하기

이 과정에서는 날짜, 파일명, 업체명, 업종, 주요 항목, 금액, 확인상태를 지정합니다. 금액은 숫자로 입력하고 통화는 별도 열로 구분하도록 요청합니다.

따라 하기

필수 열 지정 → 원문 유지 규칙 → 확인상태 구분 → Excel 저장

기억할 점 날짜나 금액이 불확실하면 “확인필요”로 남깁니다. 영문 업체명과 주요 항목은 원문대로 유지하도록 요청합니다.
06
검수

완성된 표를 원본과 대조하기

결과 파일을 열어 이미지 수와 행 수, 날짜와 금액, 중복 여부를 확인합니다. 이 과정에서는 누락된 날짜와 중복 의심 항목 등을 별도로 확인하는 과정이 이어집니다.

따라 하기

누락 점검 → 날짜·금액 대조 → 중복 확인 → 합계 점검

기억할 점 서로 다른 통화를 섞어 합산하지 않았는지, “확인필요” 항목이 합계에 어떻게 반영됐는지 확인하세요.
07
오류 대응

잘 읽히지 않는 이미지는 다시 확인하기

낮은 해상도, 그림자, 빛 반사, 구겨짐, 번진 잉크, 작은 글자, 손글씨는 읽기 오류를 만들 수 있습니다. 금액이 여러 개 표시되면 총액을 잘못 선택할 수도 있습니다.

따라 하기

정면 촬영 → 전체 영역 포함 → 충분한 밝기 → 반사·그림자 최소화

기억할 점 틀린 값은 원본을 보고 수정합니다. 읽기 어려운 부분을 AI가 임의로 채우도록 맡기지 않습니다.
08
업무 확장

다른 이미지 업무에도 적용하기

같은 흐름을 회의실 화이트보드, 명함, 제품 브로슈어, 택배 송장·납품서, 현장 점검 메모, 오류 화면에도 적용할 수 있습니다. 이미지마다 필요한 열을 먼저 정하세요.

따라 하기

이미지 모으기 → 표로 정리 → 원본 대조 → 오류 수정 → 보고용 파일

기억할 점 예: 회의 사진은 안건·결정사항·후속 작업으로, 현장 점검 메모는 항목·이상 여부·조치 내용으로 정리합니다.
PRACTICE KIT

직접 따라 해 보는 요청문

아래 지시 내용을 바탕으로 재구성한 교육용 예시입니다. 실제 폴더와 업무 기준에 맞게 수정해서 사용하세요.

1. 작업 범위와 기본 규칙

현재 선택한 실습 폴더 안에서만 작업해 줘.
원본 파일은 삭제하지 마.
먼저 이미지 파일 목록을 보여 주고, 영수증으로 보이는 파일을 구분해 줘.
개인정보, 카드번호, 승인번호, 전화번호 등 민감한 정보는 결과에 기록하지 마.
불확실한 값은 추측하지 말고 “확인필요”로 표시해 줘.
파일을 만들거나 수정한 뒤에는 변경 내용을 요약해 줘.

2. 추출 항목과 결과 형식

확인한 영수증 이미지들을 읽고 경비 정리 Excel 파일을 만들어 줘.
열: 날짜, 원본 파일명, 업체명, 업종, 주요 항목, 금액, 통화, 확인상태.
영문 업체명과 주요 항목은 원문을 유지해 줘.
금액은 숫자로 입력하고 통화는 별도 열에 적어 줘.
날짜나 금액이 불확실하면 추측하지 말고 “확인필요”로 표시해 줘.
중복으로 보이는 항목은 별도로 표시하고 임의로 삭제하지 마.
통화별 합계를 구분하고, 합계에서 제외한 항목과 이유를 알려 줘.
완료 후 처리한 파일 수, 확인필요 항목, 저장한 파일명을 요약해 줘.

통화·합계통화를 분리했나요? 제외된 금액과 이유가 보이나요?
