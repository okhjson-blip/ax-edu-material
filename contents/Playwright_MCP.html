01
개념

MCP란 무엇인가

MCP는 생성형 AI 모델이 외부에 있는 정보를 쓰기 위해 만든 규칙입니다. 굳이 비슷한 것을 찾자면 HTTP와 비슷합니다.

웹사이트에 접속할 때 도메인 앞에 붙이는 http, 이것은 Hypertext Transfer Protocol, 즉 둘 이상의 문서를 링크로 연결하는 규칙입니다. MCP나 HTTP나 데이터를 주고받는다는 점에서는 동일한 규칙입니다. 차이는 무엇을 주고받느냐에 있습니다.

구분HTTPMCP
연결 대상웹 문서와 웹 문서생성형 AI와 외부 도구·데이터
다룰 수 있는 것웹 페이지의 데이터앱, 브라우저, PC의 계산기·엑셀, 윈도우의 파일이나 폴더 등
할 수 있는 일문서를 가져와 보여주기외부 도구를 실행하거나 작동하게 하기
핵심

HTTP가 "웹 페이지의 데이터를 주고받는 것"만 할 수 있다면, MCP는 앱·브라우저·계산기·엑셀·파일까지 직접 작동시킬 수 있습니다. AI에게 손과 발을 달아주는 규칙이라고 생각하면 쉽습니다.

기억할 점 AI가 도구를 쓰려면 도구마다 연결 방식을 새로 만들어야 했습니다. MCP는 그 연결 방식을 하나의 표준으로 통일한 것입니다. USB-C 단자가 충전기·모니터·저장장치를 하나의 규격으로 묶은 것과 같은 역할입니다.
02
배경

비개발자에게 MCP가 필요한 이유

이런 점에서 비개발자가 MCP를 사용하면 비교적 간단한 방법으로 업무 자동화를 할 수 있습니다. 예를 들어 PC에서 프롬프트만으로 브라우저나 계산기 앱을 자유자재로 동작하게 할 수 있고, 프롬프트를 정교화하면 자동으로 웹페이지에서 정보를 추출하여 엑셀로 저장할 수도 있습니다.

개발자는 원래 어떻게 해왔나

일반적으로 소프트웨어 개발자는 VSCode 같은 개발 도구에 생성형 AI를 연결해서 사용합니다. 요즘에는 이미 AI가 주도하는 개발 도구로 Cursor AI, Antigravity, Claude Code, CODEX 같은 것이 다양하게 있습니다.

이런 개발 도구는 PC에 설치되기 때문에 PC의 앱이나 파일을 조작할 수 있습니다. 바로 이 점이 비개발자에게도 중요합니다 — 웹 브라우저 안에서만 도는 챗봇과 달리, 내 PC를 실제로 움직일 수 있기 때문입니다.

한 줄 정리

"개발 도구 + 생성형 AI + MCP" 조합이면, 코드를 못 써도 PC 업무를 자동화할 수 있습니다.

03
도구

Playwright, 그리고 Playwright MCP

예를 들어 MCP가 있기 전에 브라우저를 조작하려면 직접 코딩하거나, 확장 프로그램을 써서 코드로 제어하거나, 브라우저 자동화 프레임워크를 사용했습니다. 이때 많이 쓰는 자동화 프레임워크 중에 Playwright가 있습니다.

Playwright는 사람이 하는 브라우저 작업을 프로그램이 대신 수행하게 하는 도구입니다. 웹 사이트를 열거나, 버튼을 클릭하거나, 검색어를 입력하거나, 데이터를 추출하는 모든 작업이 가능합니다.

그런데 문제는

이런 Playwright를 사용하려면 사람이 코드로 Playwright를 실행해야 합니다. 그런데 생성형 AI가 Playwright를 실행하도록 연결하면, 사람은 코드를 짜지 않고 자연어로만 얘기하면 Playwright를 실행할 수 있습니다.

그래서 Playwright MCP를 개발 도구에 설치하기만 하면, 개발 도구에서 프롬프트만으로 브라우저 작업을 자동화할 수 있습니다.

Playwright (기존)Playwright MCP
실행 주체사람이 코드를 작성해 실행생성형 AI가 자연어를 해석해 실행
필요 역량프로그래밍 지식프롬프트 작성 능력
준비 작업개발 환경 구성, 스크립트 작성개발 도구에 MCP 설치 (클릭 몇 번)
현실적인 이야기

사실 말씀은 이렇게 드렸지만, 막상 개발 도구를 설치하고 Playwright를 사용하게 만드는 것은 쉽지 않습니다. 그래서 이 교육에서는 가장 빠른 길인 ChatGPT의 Codex를 이용합니다.

04
준비

실습 준비 — Codex 설치하기

그런데 ChatGPT의 CODEX를 쓰면 금방 PC 자동화를 할 수 있습니다. 물론 유료 사용자만 할 수 있기 때문에 유료 계정을 갖고 계셔야 합니다.

전제 조건

· ChatGPT 유료 계정 (무료 계정으로는 Codex 사용 불가)

· Windows PC

설치 순서

  1. ChatGPT 화면 사이드 바의 'Codex'를 눌러 Codex 화면으로 들어갑니다.
  2. Codex 화면에서 Codex 앱을 찾아 다운로드합니다. 윈도우에서 얼마든지 설치 가능합니다.
  3. 설치가 끝나면 Codex를 실행합니다.

첫 실행 — 작업 폴더 선택

Codex를 실행하면 처음 시작할 때 폴더를 하나 선택하라고 나올 겁니다. 실습용으로 CodexP처럼 폴더를 하나 만들어 두고 선택하면 됩니다. 필요하면 로그인하라고 나오니까, ChatGPT 유료 계정이 있으면 그대로 로그인하시면 됩니다.

기억할 점 Codex는 원래 개발 도구입니다. 작업 결과 파일을 저장할 기준 폴더가 필요해서 묻는 것입니다. 실습용으로 빈 폴더를 하나 새로 만들어 지정하면 기존 파일이 건드려질 걱정이 없습니다.
05
확인

Codex 첫 실행과 동작 확인

PC 기반의 개발 도구에 여러 가지 AI까지 덧붙여져 있는 거라고 생각하시면 됩니다. 처음에 보면 되게 어려워 보이는데요, 그냥 "안녕" 이라고 얘기해 보면 우리가 ChatGPT 웹 서비스에서 쓰는 방법과 아주 크게 다른 것은 아니라는 걸 알 수 있습니다.

첫 테스트 프롬프트안녕

웹 서비스에서는 금방 대답을 하는데 여기서는 대답을 늦게 할 수 있습니다. 왜냐하면 중간중간에 필요한 프로그래밍 코딩 작업들이 있는 경우가 있기 때문입니다.

'안녕하세요! 무엇을 도와드릴까요?'라고 답하면서, 이게 기본적으로 AI 기반의 코딩 도구이다 보니까 코딩 / 문서 정리 / 버그 수정 / 자동화 같은 것들을 물어봅니다.

체크포인트

여기까지 답변이 돌아왔다면 설치와 로그인은 정상입니다. 응답이 웹 ChatGPT보다 느린 것은 정상 동작입니다.

06
설치

Playwright MCP 설치하기

그럼 브라우저를 어떻게 조작하는지 한번 볼까요? 자, 크롬 브라우저를 한번 열어보겠습니다. 이때 크롬 브라우저 같은 걸 조작하기 위해 Playwright MCP를 추가해 줘야 한다는 거죠.

  1. 왼쪽에 '설정'이 있습니다. 설정으로 들어갑니다.
  2. 설정의 메뉴를 보면 'MCP 서버'가 보일 겁니다.
  3. 여기 MCP 서버에 여러 가지가 있는데요, 밑에 보시면 'Playwright'가 있습니다.
  4. 만약 직접 추가를 하겠다고 하면 '서버 추가'를 눌러서 필요한 정보들을 넣어주면 됩니다.
  5. 목록에 있는 경우에는 '설치하기'를 눌러 그냥 설치하시면 됩니다.

여기에 'Playwright'가 있으면 '설치하기'를 눌러 설치하면 됩니다. Figma나 Notion 같은 게 필요하면 여기 '설치하기'를 눌러서 그냥 설치하시면 됩니다. 필요한 경우에는 이런 식으로 인증(로그인)이 필요한 경우가 있습니다.

불필요한 것은 그대로 해제를 하면 되고요. 설치 후 필요한 설정들이 있는데, 이 설정들은 이미 기본적으로 들어가 있으니까 그대로 놔두면 됩니다.

기억할 점 Linear, Notion, Figma, Playwright 등이 기본 목록으로 제공됩니다. 업무에서 쓰는 도구가 목록에 있으면 설치 버튼 한 번으로 AI와 연결되고, 없으면 '서버 추가'로 직접 등록합니다.
07
실행

프롬프트로 크롬 브라우저 열기

이제 프롬프트 입력하는 화면으로 돌아왔고요. 이제 여기에서 크롬 브라우저를 열면 됩니다. 아까 Playwright를 설치했으니까요.

프롬프트크롬 브라우저를 열어줘 (Playwright를 사용해서)

권한 승인 — 가장 중요한 단계

그러면 Playwright를 이용해서 크롬 브라우저를 열기 위해서 우리에게 승낙을 요구합니다. Playwright MCP 서버가 브라우저 내비게이터 툴을 작동하려고 하는데 허락할 거냐고 묻는 것이고, 정확히는 이번 세션에서 허락할 거냐고 묻는 겁니다. 1번이나 2번을 눌러주시면 되고, 실습에서는 2번을 선택하면 됩니다.

선택지의미권장
1. Allow once이번 한 번만 허용처음 써보는 도구일 때
2. Allow for this session이번 세션(작업) 동안 계속 허용실습 시 권장 — 매번 묻지 않음
3. Cancel거부의도하지 않은 요청일 때
주의

승인 창은 AI가 내 PC의 프로그램을 실제로 건드리기 직전에 뜹니다. 내가 시킨 작업과 관련된 요청인지 확인하고 승인하세요. 작업 중간중간 새로운 작업을 해야 할 때마다 다시 물어봅니다.

승인이 끝나면 브라우저가 열립니다. 오른쪽에 프롬프트 입력창, 왼쪽에 크롬 브라우저로 화면을 나누면 AI의 동작을 눈으로 따라가기 좋습니다.

08
실전

실전 — 네이버 뉴스 수집 자동화

그러면 Playwright를 이용해서 왼쪽 크롬 브라우저를 작동하는 거죠. 왼쪽 브라우저에서 입력하기 위해 또 필요한 툴이 있으니까 이 툴을 사용할 건지 물어봅니다. 2번을 선택합니다.

① 검색어 입력

바로 입력합니다. 그러면 '삼성전자'가 입력된 화면에서 그대로 또 엔터를 치겠죠?

② 카테고리 이동 + 목록 추출

이번에는 여기 뉴스 카테고리가 있으니까, 삼성전자를 입력해서 여러 개 항목들 중 '뉴스' 쪽을 클릭하는 것을 볼 수 있습니다. 그리고 필요한 뉴스 목록을 뽑아달라고도 할 수 있겠죠.

프롬프트 예시네이버에서 '삼성전자'를 검색하고, 뉴스 탭으로 이동해서 상위 뉴스 목록을 뽑아줘

그러면 왼쪽 크롬 브라우저의 네이버 뉴스 화면에서 뉴스 목록을 뽑아줍니다.

③ 새 탭 열고 다른 사이트로

이어서 왼쪽 브라우저에서 새 탭을 열어서 구글에 접속할 수 있습니다.

이 실습에서 AI가 수행한 브라우저 동작

브라우저 실행 → 주소 이동 → 검색어 입력 → 엔터 → 탭(카테고리) 클릭 → 목록 데이터 추출 → 새 탭 열기 → 다른 사이트 접속. 사람이 마우스로 하던 일을 그대로 문장으로 지시한 것이 전부입니다.

업무 적용 매일 아침 특정 키워드 뉴스 목록을 뽑아 정리하기, 경쟁사 사이트의 제품·가격 페이지에서 정보 수집하기, 사내 시스템의 반복 조회 화면을 열어 결과만 받아보기. 프롬프트를 정교화하면 추출 결과를 엑셀로 저장하는 데까지 이어갈 수 있습니다.
정리

정리와 다음 단계

생성형 AI를 이용해서 외부 정보나 도구, PC의 앱이나 파일을 자유자재로 다루는 방법은 많습니다. 그런데 이런 방법이 다 제각각이어서 뭔가 하나를 하려고 해도 쉽지가 않습니다.

점점 생성형 AI가 업무의 중심이 되고, 다양한 데이터·앱·도구가 AI를 중심으로 연결되고 있어서 비개발자도 쉽게 쓸 수 있는 연결 방법이 필요했습니다. 마침 적절한 때에 MCP가 나왔습니다.

도전해 보세요

물론 너무나도 낯선 개념이고 평소에 익숙하지 않은 개발자 마인드가 약간 필요하긴 합니다. 하지만 들이는 시간에 비해 효과가 크고, 결국 앞으로 이런 것을 직접 연결해서 일해야 하므로 지금 바로 도전해 보시기 바랍니다.
